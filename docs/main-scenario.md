# 응원공방 메인 시나리오

## 실행 흐름

### 1. 아티스트 등록
- 아티스트 role이 부여되며, 생성된 AI 굿즈 신고하기 기능이 제공된다.

---

### 2. 업체 등록
업체는 자신이 제작 가능한 정보를 입력한다.

| 항목 | 내용 |
|------|------|
| 제작 가능 종류 | 머그컵, 팔찌, 가죽지갑 등 |
| 최소/최대 수량 | 7일 내 가능한 수량 기준 |
| 개수 단위별 금액 | 수량 범위 설정 칸 - 금액 (계속 추가 가능) |
| 배송비 | 별도 입력 |

---

### 3. AI 굿즈 생성과 확정 단계

1. **나의 아티스트 설정**
2. 아티스트가 등록한 공식 자료를 AI 모델과 함께 사용하여 굿즈를 생성한다.
3. 마음에 드는 굿즈가 생성되었을 경우, **1차 등록**을 진행한다. (생성 자료 사진 + 업체 선택)
4. 1차 등록 후 선택한 업체에 제안을 보낸다.
   - 거절될 경우 → 다른 업체에 다시 제안을 보낸다.

---

### 4. 참여자 모집

1. 승낙된 금액(최소/최대 수량)과 디자인을 기반으로 참여자 모집이 시작된다.
2. 다른 참여자들은 제안된 굿즈와 최대 금액을 보고 참여 여부를 선택 후 결제한다.
   - 배송비 별도
3. 목표 개수 달성 또는 기간 완료 시, 해당 개수에 맞는 금액으로 제작이 시작된다.
   - 처음 제시된 금액은 1개 기준(최대 금액)이므로, 줄어든 금액은 환불된다.

---

### 5. 제작 시작

- 업체 측에서 진행 과정을 공유한다.
- 사용자는 **마이페이지 > 나의 주문 현황**에서 조회 가능하다.

| 단계 | 상태 |
|------|------|
| 1 | 주문 접수 |
| 2 | 제작 중 |
| 3 | 제작 완료 |
| 4 | 배송 중 |

---

### 6. 배송

- 굿즈 제작 완료 후, 비대면 서비스 특성상 모두 **개별 배송**으로 진행된다.

---

### 7. 아티스트의 이득

- 소속사가 없거나 지원이 어려운 아티스트의 경우, 팬들의 니즈를 충족시킬 수 있다.
- **수수료 정책**: 구매 금액의 일정 퍼센트를 아티스트에게 지급한다.
  - 명목: 아티스트 캐릭터 및 디자인 사용료
  - 방식: 고정 퍼센트 (비율 추후 확정)
